# Shared skill use policy

Follow the user brief and the current project AGENTS.md before upstream defaults. Preserve user code and already-made decisions; make only the requested changes. This shared skill library is maintained at https://github.com/sxy3481841323-ship-it/agent-skills. New reusable skills belong in that master library before synchronization to client global directories.

Map host-specific tools, slash commands and optional hooks to the tools actually available. Do not run nonexistent .claude hooks or pretend a missing service worked. Prefer the platform-provided image and browser tools. Exact diagrams and factual charts require deterministic tools. A generative-art coding request may use its specified code framework.

Existing authorization covers routine reversible work. Ask only for missing decisions that materially affect the task; do not add repeated approval gates because an upstream template says to ask. Never discard user edits to satisfy a workflow.

External API credentials, software, browsers and downloads are separate prerequisites; installing this skill does not activate paid services. Check prerequisites when needed and report actual validation limits. Never start news ingestion or paid generation merely to install or test skill discovery.

Template interaction structure is reusable, but user-specified colors and branding take priority over Anthropic-branded sample defaults. Use brand-guidelines only for an explicitly requested Anthropic look.
